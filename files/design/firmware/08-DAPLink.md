# HEX-Bridge 网络调试探针规约（DAPLink 功能）

状态为待开发。首版交付 OpenOCD 可用的 CMSIS-DAP over TCP / SWD 探针。USB HID、USB Bulk、拖盘烧录、JTAG 和 SWO 均在本期范围之外。

## 接口与边界

| 服务 | 端点 | 约定 |
|---|---|---|
| CMSIS-DAP | Wi-Fi STA，TCP 4441 | 一个调试客户端独占 SWD；忙时关闭新连接，保留原会话 |
| UBCP v2 | UART1 或 TCP 9500 | 复用既有帧格式和 CAN/UART 命令，按[单活规则](05-Bridge-Design.md#74-单活链路与切换边界开发规约)切换 |
| 公网访问 | 已有 VPN 可直接使用上述端点 | 如另行开发中继，设备主动建立认证的 WSS 连接，按服务分别转发字节流；本地与中继争用同一服务的席位 |

DAP 在取得 IP 后监听，失去 IP 时关闭连接并释放引脚，重新取得 IP 后恢复。设备上电、空闲或客户端异常退出时应释放 SWDIO 和可选复位线。网络任务、DAP 延时和慢客户端发送均不得持有 UBCP 总线锁。

## OpenOCD 线上格式

每帧含 8 字节头和一个 CMSIS-DAP 命令或响应。头的字节 0–3 为 44 41 50 00（十六进制），4–5 为小端载荷长度，6 为类型（请求 1、响应 2），7 为保留位，发送时置零。长度包含命令字节。首版每包上限 1024 字节；DAP_Info 返回的包长和包数必须与实际缓冲能力一致。按长度组帧，支持拆包、粘包、短写和有序响应。签名错误、类型错误、空包、越界长度或半帧断开时终止该连接并清理状态。

以参考工程的 dap_ctrl.c 和 tcp/dap.c 为兼容基线。至少支持探针信息、SWD 连接/断开、时钟设置、SWJ 序列、SWD 配置、单次/块传输及 OpenOCD 初始化所需的引脚控制；正确报告 WAIT、FAULT 和不支持的命令。只宣告已实现的能力。命令执行与板级 GPIO 时序分离，SWDIO 读写换向前释放驱动。默认采用保守时钟，上限由目标板实测决定。复位脚未接时按无硬件复位配置调试。

## 接线与验收

接线以[引脚表](../../sch/esp32-pinout-design.md)为准。验收记录应列出目标板、OpenOCD 版本、目标配置、SWD 时钟和实际接线。

1. 主机测试覆盖协议头、拆包、粘包、超长帧、第二客户端竞争和连接中断。重新连接后可以重新初始化目标。
2. 用支持 CMSIS-DAP TCP 后端的 OpenOCD 连接设备 IP 和端口 4441，识别目标，暂停、读寄存器、恢复。对允许写入的测试目标另验写入及回读校验。
3. 调试期间运行 CAN 和 UART 收发，检查回复、异步上报和调试请求各自到达正确连接。覆盖 UBCP 单活切换、积压数据、掉线和恢复。
4. 分开记录主机测试、固件构建与实板结果。缺少目标板或适配器时列明未验证项。
