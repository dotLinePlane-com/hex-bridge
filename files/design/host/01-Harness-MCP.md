# HEX-Bridge 主机端 MCP Server

Harness 通过标准输入输出启动一个本地 MCP 进程。该进程把工具请求编码为 UBCP v2，经 UART1 或 Wi-Fi TCP 9500 访问一台设备。安装入口与配置样例见 [mcp/README.md](../../../mcp/README.md)。

## 当前固件功能与映射

以下清单依据 main/main.c 的模块注册、各模块的命令处理函数及协议定义。具体板卡启用的通道受运行中的设备配置约束，可用 device_info 和 GET_TOPOLOGY 查询。

| 接口 | 已实现的功能 | Harness 使用方式 |
|---|---|---|
| 系统 | 心跳、设备信息、配置读写、复位、流控、拓扑、设备配置事务 | device_info 或系统命令，设备配置使用 DEVICE_PROFILE |
| CAN / CAN FD | MCP2518FD 开关、配置、发送、滤波、状态、休眠与唤醒 | CAN 命令；接收帧、总线和错误通知从事件队列读取 |
| UART | 两路业务串口按配置启用，支持配置、发送、Break、状态及缓冲清理 | UART 命令及接收事件 |
| SPI | 两个主机设备通道，支持读写、全双工、片选；两个从机通道支持预装与领取数据 | SPI 命令 |
| I²C | 双控制器、扫描、读写、重复起始 | I2C 命令 |
| GPIO | 输入输出、偏置、中断、组读写 | GPIO 命令及中断事件 |
| Wi-Fi / 网络 | STA 配网、IPv4、DNS、连接管理和链路事件 | WIFI 和 NET 命令 |
| TCP / UDP / WebSocket | 服务端、客户端、数据收发及连接管理 | TCP、UDP、WS 命令及异步事件 |
| CMSIS-DAP / SWD | 独立的 TCP 4441 调试探针 | dap_info 查询探针信息，SWD 调试和下载由 OpenOCD 等 CMSIS-DAP 客户端执行 |

Bulk、OTA 目前只有预留协议。本清单描述固件实现情况，实板可用性还取决于外设接线与 Profile。

## 工具与会话

catalog 离线列出请求和事件。protocol_guide 提供随安装包发布的载荷定义。request 按命令名、通道及十六进制载荷发起操作；返回状态、原始响应和通道。device_info 将常用身份字段解码为 JSON。next_event 领取异步帧。disconnect 释放设备。

一个进程维持一条设备连接，第一次设备操作才打开连接。请求串行执行，按序号及命令匹配响应。接收线程持续解析帧并保留最近 256 个事件，报告覆盖数量。超时表示执行结果未知，由调用方决定下一步；自动重发可能重复发送总线数据。设备断开后清理旧会话，下次调用可重新连接。

## 后续变更

在同一项功能变更中更新固件、协议、主机命令目录或工具参数、设计映射与包版本。检查事件方向和旧版固件的响应，重新构建安装包，在独立环境完成 MCP 握手、工具发现和对应操作测试。维护约定见根目录 AGENTS.md。
