# Legacy Ethernet archive

These files describe or implement the retired LAN8720 Ethernet variant. They are retained for reference only and are not included in the active firmware build. Current network connectivity uses the ESP32 Wi-Fi STA implementation. Current GPIO assignments are defined by `files/sch/esp32-pinout-design.md`.

`09-Network-Tests-ethernet-legacy.md` is the original Ethernet-oriented network test plan. The active test plan at `files/design/test/09-Network-Tests.md` covers the retained network commands without an Ethernet link assumption.
